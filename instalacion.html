Dos modos, una biblioteca

Elige cómo trabajar. La instalación real de un ZIP y la conexión MCP dependen de las capacidades y permisos de tu versión de ChatGPT.

Modo sencillo: sin infraestructura

1

Obtén el complemento por un canal privado

Descarga el complemento v0.5.0 desde la sección Descargas de este repositorio público. También encontrarás el backend v0.5.0 y el prototipo visual v0.6.0. Consulta la licencia de uso limitado antes de utilizarlos.

2

Comprueba que tu ChatGPT permita la instalación

La carga manual de complementos está sujeta a los permisos de la cuenta o espacio de trabajo. Si no puedes cargarlo, no es un error de tu novela: la función puede no estar habilitada.

3

Elige “Modo sencillo”

Proporciona el contexto de tu universo y comienza con una ficha de personaje, una cronología o una auditoría editorial. Guarda o exporta los registros importantes por tu cuenta.

Qué obtienes: asesoría de continuidad sin configurar infraestructura. Qué no obtienes: una base de datos externa con guardado automático.

Modo persistente: infraestructura propia

Esta alternativa sigue en desarrollo y no debe interpretarse como conexión inmediata. Cada escritor es responsable de su servidor, identidad, respaldos y posibles costes.

1

Selecciona alojamiento

El asistente técnico contempla Render, Railway, Fly.io o servidor propio. Antes de desplegar, confirma las condiciones y precios del proveedor elegido.

2

Prepara almacenamiento

La configuración actualmente documentada se basa en SQLite persistente. No supongas que PostgreSQL está disponible sin un adaptador adicional.

3

Configura identidad

La elección prevista contempla Auth0, Keycloak o Amazon Cognito para acceso remoto, aunque los flujos aún deben validarse de extremo a extremo. No compartas secretos ni contraseñas en ChatGPT.

4

Protege la conexión

Un servidor público debe utilizar HTTPS y autenticación; nunca expongas SQLite directamente. El modo sin autenticación solo corresponde a una instalación aislada de prueba en localhost.

5

Registra y prueba MCP en ChatGPT

Cuando el servidor esté desplegado, verifica un endpoint MCP real, registra la conexión mediante la opción compatible con tu cuenta y comprueba la lectura/escritura con datos ficticios.

Advertencia: GitHub Pages aloja este sitio informativo, no ejecuta Python, SQLite ni un servidor MCP persistente.

Portabilidad

La arquitectura busca permitir exportar registros e importarlos en otra instalación. La recuperación, restauración y migración entre proveedores todavía requiere pruebas completas antes de confiarle manuscritos originales.

Guías detalladas para descargar

Si nunca has instalado un complemento o un servidor, comienza por la Guía completa de instalación y uso (Markdown). Explica ambos modos con ejemplos, advertencias y solución de problemas.

Si vas a continuar el desarrollo, consulta la Hoja de ruta técnica (Markdown), con los hitos pendientes y criterios de prueba.

Documentación técnica

El desarrollador puede proporcionar el paquete del backend y el complemento por separado. Para detalles del estado actual, consulta el informe de estado técnico.

Descarga los archivos necesarios

Los tres paquetes están publicados en este repositorio. Para comenzar, descarga el complemento v0.5.0; el backend es para el modo persistente y la interfaz v0.6.0 es experimental.
