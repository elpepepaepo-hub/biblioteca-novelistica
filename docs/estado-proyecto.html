Principio de responsabilidad

El objetivo de arquitectura es que cada escritor sea propietario y administrador de su propia infraestructura. No existe una base de datos central hospedada por el desarrollador.

Este repositorio contiene documentación pública y los tres ZIP oficiales de Biblioteca Novelística. Los ZIP incluyen código del complemento, backend e interfaz experimental; no deben contener bases de datos personales, claves API ni credenciales.
